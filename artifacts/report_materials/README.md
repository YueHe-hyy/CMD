# Report materials

`source_validation_samples.zip` contains four selected CMD source-domain validation frames for qualitative analysis:

- Pedestrian: `seq38/0001` (34.6 m), `seq38/0038` (30.5 m)
- Truck: `seq08/0197` (51.4 m), `seq07/0085` (51.3 m)

For every frame, the archive contains the original Ouster and Hesai point clouds, original JSON labels, sensor-to-ego calibration matrices, and the aligned epoch-46 predictions. A detailed Chinese manifest is included inside the archive.

The archive contains no target-domain test labels and no full CMD dataset.
